# The One Prompt

This whole game was built from this single prompt:

> Build a tiny neon arcade browser game in a single page: a glowing ship dodges
> falling asteroids and collects stars. Steer with mouse or arrow keys/WASD.
> Speed ramps up over time, particles and screen shake on hits and pickups,
> score and combo HUD, shield pickup, game over screen with restart, plus a
> demo autopilot mode that plays itself. Dark space background with a starfield,
> neon pink/cyan palette, 60fps canvas.

Files: `index.html` + `style.css` + `game.js`. Open `index.html` in a browser
to play. Add `?demo=1` to watch the autopilot play itself.
